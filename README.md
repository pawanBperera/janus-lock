# Janus Lock

A small, local, encrypted file vault. Learning project.

> ⚠ **Not audited. Not production crypto. Don't store your real passwords in it.**
> Use [KeePassXC](https://keepassxc.org/) for that.

Named after Janus, the two-faced Roman god of doorways — one face encrypts, one decrypts.

 Work in progress. Building in public.
